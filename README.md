# Queequeg

A local film-inspired RAW photo editor for macOS.

This repository hosts public app downloads. The source repository is private.

## Downloads

The first Developer ID signed and Apple-notarized release is being prepared. There is no public app download yet.

When available, downloads will appear on the [Releases page](https://github.com/lvenneri/queequeg-releases/releases). Requirements: Apple silicon and macOS 26 or later. Extract the ZIP and move Queequeg.app into Applications.

Queequeg processes photographs locally. Update checks happen when you choose **Help → Check for Updates**; they contact GitHub, without sending your photos or library metadata. Updates are checked against a SHA-256 checksum and the Apple signing identity pinned in the installed release.

Catalog backups contain organization records, not your photographs. Keep a separate backup of your library's Originals and Exports folders.

Third-party notices are included in the app under Help.
